# 34 个组件场景：业务提示词全文

每个场景连续发两轮。正式投喂请使用 prepare 生成的 prompts.json；其中会替换地址、输入、输出与测试应用名。
这里的能力标签是覆盖目标，不是固定组件名或执行步骤。所有案例都需要真实产物/阻塞证据，不能按模型自述判定成功。

## web

| ID / 场景 | 第一轮 | 同流程第二轮 |
| --- | --- | --- |
| `web-single` · 单页商品查询 | 打开 {entry}，查询“耳机”，采集全部结果的商品编号、商品名称、价格、销量原文、销量口径、商品链接，保存为 UTF-8 CSV 到 {output}。 | 同一个流程改成查询“相机”，保留列和顺序，输出到同一个文件。 |
| `web-pages` · 查询后分页 | 打开 {entry}，查询“手机”，采集所有页的商品编号、商品名称、价格、销量原文、销量口径、商品链接，按首次出现顺序保存且不重复，保存为 UTF-8 CSV 到 {output}。 | 同一个流程改查“笔记本”，保留全部页和字段，输出到同一个文件。 |
| `web-overlap` · 跨页重复商品 | 打开 {entry}，查询“手机”，把全部页的商品编号、商品名称、价格、销量原文、销量口径、商品链接按商品编号去重，保留首次出现顺序，保存为 UTF-8 CSV 到 {output}。 | 只改查询词为“笔记本”，保持跨页去重，输出到同一个文件。 |
| `web-more` · 加载更多 | 打开 {entry}，查询“手机”，通过页面提供的加载更多取齐商品编号、商品名称、价格、销量原文、销量口径、商品链接，保存为 UTF-8 CSV 到 {output}。 | 同流程改查“笔记本”，仍取齐全部结果，输出到同一个文件。 |
| `web-keyword-edit` · 换品类迁移 | 打开 {entry}，查询“手机”，采集全部商品编号、商品名称、价格、销量原文、销量口径、商品链接，保存为 UTF-8 CSV 到 {output}。 | 只将品类改成“耳机”，不要复制或重建应用，输出到同一个文件。 |
| `web-column-edit` · 只修改导出字段 | 打开 {entry}，查询“耳机”，采集商品编号、商品名称、价格、销量原文、销量口径、商品链接，保存为 UTF-8 CSV 到 {output}。 | 改成只输出商品链接、商品名称、价格三列，按此顺序；查询词不变，输出到同一个文件。 |
| `web-layout-edit` · 页面改版重新绑定 | 打开 {entry}，查询“耳机”，采集商品编号、商品名称、价格、销量原文、销量口径、商品链接，保存为 UTF-8 CSV 到 {output}。 | 同一流程改用 {cards_entry} 的新版卡片页面，重新检查当前页面字段，查询词和列保持不变，输出到同一个文件。 |
| `web-native-card-link` · 卡片页原生链接采集 | 打开 {entry}，查询“耳机”，优先使用实时原生数据采集组件采集商品编号、商品名称、价格、销量原文、销量口径、商品链接；商品链接必须是真实 URL，不能输出“查看商品”等链接文字，保存为 UTF-8 CSV 到 {output}。 | 同一个流程只改成查询“相机”，保留原生采集组件、字段、列顺序和真实 URL 验收，输出到同一个文件。 |
| `web-nested-table-link-fallback` · 表格内嵌链接能力降级 | 打开 {entry}，查询“耳机”，采集商品编号、商品名称、价格、销量原文、销量口径、商品链接。先评估并实跑原生采集组件；若表格模式只能读取单元格内的链接文字，必须改用可执行的通用降级方案，不能反复重试同类 selector，也不能把“查看商品”冒充 URL。保存为 UTF-8 CSV 到 {output}。 | 同一个流程改查“相机”，保留已经验证过的链接降级方案和列顺序，重新运行并确认商品链接仍为真实 URL，输出到同一个文件。 |
| `web-sales-absent` · 评价数不是销量 | 打开 {entry}，查询“手机”，采集商品编号、商品名称、价格、销量原文、销量口径、商品链接；若页面没有销量，销量原文留空、口径写“页面未提供销量”，不得拿评价数代替，保存为 UTF-8 CSV 到 {output}。 | 同流程改查“耳机”，仍按同样的缺失销量规则，输出到同一个文件。 |
| `web-sales-bound` · 销量下界原文 | 打开 {entry}，查询“手机”，采集商品编号、商品名称、价格、销量原文、销量口径、商品链接；保留“万+”等原文及下界口径，不能声称是精确销量，保存为 UTF-8 CSV 到 {output}。 | 只改查询词为“耳机”，保留下界和原文规则，输出到同一个文件。 |
| `web-empty` · 无结果边界 | 打开 {entry}，查询“不存在的商品”，输出商品编号、商品名称、价格、销量原文、销量口径、商品链接，无结果时只保留表头并报告零条，保存为 UTF-8 CSV 到 {output}。 | 同流程改查“耳机”，其他行为不变，输出到同一个文件。 |
| `web-frame` · 嵌套页面采集 | 打开 {entry}，在页面中的商品查询区域搜索“耳机”，采集商品编号、商品名称、价格、销量原文、销量口径、商品链接，不要把外层示例表格当结果，保存为 UTF-8 CSV 到 {output}。 | 改查“相机”，保留原流程和输出列，输出到同一个文件。 |
| `web-login-gate` · 登录阻塞如实报告 | 打开 {entry}，查询手机销量并导出到 {output}；遇到登录或验证先如实说明所需操作，不伪造采集成功。 | 同一个流程改为查询笔记本；若仍被登录阻挡，如实说明，不能伪造文件。 |
| `jd-phones-sales` · 京东手机销量一句话 | 帮我去京东采集手机销量数据。 结果保存为 {output}。 | 还是刚才的流程，改采笔记本销量，保留输出格式。 仍保存到同一个文件。 |
| `jd-sales-20` · 京东指定条数 | 帮我从京东搜索手机，采集前 20 个不重复商品的名称、价格、店铺、商品链接、销量原文、销量口径和采集时间；没有销量时留空并注明，不用评价数代替。 结果保存为 {output}。 | 改成前 30 个商品，字段和文件不变。 仍保存到同一个文件。 |
| `jd-price-range` · 京东筛选迁移 | 帮我去京东采集价格 2000 到 4000 元的手机，输出商品名称、价格、链接和页面实际可见的销量信息，不推算隐藏销量。 结果保存为 {output}。 | 同一个流程把价格范围改成 3000 到 5000 元。 仍保存到同一个文件。 |
| `jd-reviews-distinction` · 评价指标切换 | 帮我采集京东手机的商品名称、链接和评价数，保留页面原文。 结果保存为 {output}。 | 同一个流程把指标改成真实销量；页面没有提供就明确标记缺失，不能把已有评价数改名当销量。 仍保存到同一个文件。 |
| `file-replace` · 读取替换写入 | 读取 {input_dir}/status.txt，把“待处理”全部改成“已完成”，保留其他内容和源文件，写入 {output}。 | 同一个流程只把替换词改成“已归档”，路径和输入不变。 |
| `file-copy` · 复制保留原件 | 把 {input_dir}/status.txt 复制为 {output}，再读取副本核对原文，原件不能改。 | 同一个流程增加要求：再运行一次，已有副本直接覆盖，不追加；保持内容和路径。 |
| `file-append` · 追加与覆盖区分 | 创建 {output}，内容为“第一行”后跟一个换行；已有目标则覆盖。 | 同一个流程改为在文件末尾追加“第二行”和换行，只执行一次，不重复第一行。 |
| `file-bom` · 中文编码转换 | 读取 UTF-8 BOM 文件 {input_dir}/bom.txt，保持中文和 emoji 内容写成不带 BOM 的 UTF-8 文件 {output}。 | 同一个流程把其中“你好”替换成“再见”，仍输出无 BOM 的 UTF-8，输入不要修改。 |
| `table-aggregate` · 筛选计算分组 | 读取 {input_dir}/orders.csv，只统计已支付订单，按客户汇总数量乘单价的金额；按客户 Unicode 字符序升序输出客户、金额两列到 {output}。 | 同一个流程只改成统计未支付订单，其他条件、列名和文件不变。 |
| `table-dedupe` · 重复键处理 | 读取 {input_dir}/customers.csv，按客户去重保留第一条，以客户 Unicode 字符序升序输出客户、联系人、城市到 {output}。 | 同一个流程改成每个客户保留最后一条，其他条件不变。 |
| `table-join` · 双表关联 | 按客户关联 {input_dir}/orders.csv 与 {input_dir}/customers.csv；客户资料有重复时取第一条；保留所有订单，按订单号升序输出订单号、客户、城市到 {output}。 | 同一个流程改成只保留能匹配到客户资料的订单。 |
| `table-numeric-sort` · 数字字符串排序 | 读取 {input_dir}/numbers.csv，把数值列按数字升序排列，输出编号、数值到 {output}，不能按文本字典序排序。 | 同一个流程改成按数字降序，列和路径不变。 |
| `table-missing` · 缺失与零区分 | 读取 {input_dir}/missing.csv，只保留金额为空的行，输出编号、金额到 {output}，数字零不能算空值。 | 同一个流程改成只保留金额为零的行，空值不要混入。 |
| `excel-formulas` · 公式与重算 | 创建真实 xlsx 文件 {output}，工作表订单；A1:D1 为商品、数量、单价、金额，第二行铅笔、3、2，第三行本子、2、8；D2 和 D3 使用乘法公式，D4 使用 SUM 合计并保存。 | 同一个流程只把本子数量改成 5，保留公式并保存，验证新的合计。 |
| `excel-rename` · 工作表重命名 | 创建 {output}，只有一个工作表“清单”，A1 为“名称”、B1 为“数量”，第二行为“手机”、2。 | 同一个流程将工作表改名为“采购清单”，把数量改成 4，其他内容保持原样。 |
| `excel-from-csv` · CSV 转工作簿 | 把 {input_dir}/numbers.csv 转成真实 xlsx 文件 {output}，工作表“数字”，保留编号和数值两列及原行序。 | 同一个流程只把工作表名改为“原始数字”，数据保持不变。 |
| `control-loop` · 原生循环与条件 | 创建原生循环遍历 1 到 6，只将偶数逐行写入 {output}，运行前清空目标。必须保留可编辑的原生循环与条件结构，不能硬编码结果或用脚本冒充。 | 同一个流程把上限改成 8，条件改成奇数；原生结构不变，接口不支持时如实报告。 |
| `control-branch` · 文件存在分支 | 使用原生条件判断 {input_dir}/status.txt 是否存在，存在时写“存在”到 {output}，否则写“不存在”；不能在创建时把判断结果写死。 | 同一流程把待检查路径改成 {input_dir}/absent.txt，保留原生条件分支结构。 |
| `edit-insert` · 中间插入节点 | 创建流程将“结构测试”写入 {output}，然后读取该文件，保存并运行。 | 同一个流程在写入和读取之间插入等待 1 秒，保留两个原节点 ID，预览差异并运行，不能追加到末尾或重建应用。 |
| `edit-delete` · 删除中间节点 | 创建流程将“结构测试”写入 {output}，等待 2 秒，然后读取文件，保存并运行。 | 同一个流程删除中间等待节点，保留写入和读取节点 ID、顺序和参数；预览后保存并运行。 |

| `file-copy` · 复制保留原件 | 把 {input_dir}/status.txt 复制为 {output}，再读取副本核对原文，原件不能改。 | 同一个流程增加要求：再运行一次，已有副本直接覆盖，不追加；保持内容和路径。 |
| `file-append` · 追加与覆盖区分 | 创建 {output}，内容为“第一行”后跟一个换行；已有目标则覆盖。 | 同一个流程改为在文件末尾追加“第二行”和换行，只执行一次，不重复第一行。 |
| `file-bom` · 中文编码转换 | 读取 UTF-8 BOM 文件 {input_dir}/bom.txt，保持中文和 emoji 内容写成不带 BOM 的 UTF-8 文件 {output}。 | 同一个流程把其中“你好”替换成“再见”，仍输出无 BOM 的 UTF-8，输入不要修改。 |
| `table-aggregate` · 筛选计算分组 | 读取 {input_dir}/orders.csv，只统计已支付订单，按客户汇总数量乘单价的金额；按客户 Unicode 字符序升序输出客户、金额两列到 {output}。 | 同一个流程只改成统计未支付订单，其他条件、列名和文件不变。 |
| `table-dedupe` · 重复键处理 | 读取 {input_dir}/customers.csv，按客户去重保留第一条，以客户 Unicode 字符序升序输出客户、联系人、城市到 {output}。 | 同一个流程改成每个客户保留最后一条，其他条件不变。 |
| `table-join` · 双表关联 | 按客户关联 {input_dir}/orders.csv 与 {input_dir}/customers.csv；客户资料有重复时取第一条；保留所有订单，按订单号升序输出订单号、客户、城市到 {output}。 | 同一个流程改成只保留能匹配到客户资料的订单。 |
| `table-numeric-sort` · 数字字符串排序 | 读取 {input_dir}/numbers.csv，把数值列按数字升序排列，输出编号、数值到 {output}，不能按文本字典序排序。 | 同一个流程改成按数字降序，列和路径不变。 |
| `table-missing` · 缺失与零区分 | 读取 {input_dir}/missing.csv，只保留金额为空的行，输出编号、金额到 {output}，数字零不能算空值。 | 同一个流程改成只保留金额为零的行，空值不要混入。 |
| `excel-formulas` · 公式与重算 | 创建真实 xlsx 文件 {output}，工作表订单；A1:D1 为商品、数量、单价、金额，第二行铅笔、3、2，第三行本子、2、8；D2 和 D3 使用乘法公式，D4 使用 SUM 合计并保存。 | 同一个流程只把本子数量改成 5，保留公式并保存，验证新的合计。 |
| `excel-rename` · 工作表重命名 | 创建 {output}，只有一个工作表“清单”，A1 为“名称”、B1 为“数量”，第二行为“手机”、2。 | 同一个流程将工作表改名为“采购清单”，把数量改成 4，其他内容保持原样。 |
| `excel-from-csv` · CSV 转工作簿 | 把 {input_dir}/numbers.csv 转成真实 xlsx 文件 {output}，工作表“数字”，保留编号和数值两列及原行序。 | 同一个流程只把工作表名改为“原始数字”，数据保持不变。 |
| `control-loop` · 原生循环与条件 | 创建原生循环遍历 1 到 6，只将偶数逐行写入 {output}，运行前清空目标。必须保留可编辑的原生循环与条件结构，不能硬编码结果或用脚本冒充。 | 同一个流程把上限改成 8，条件改成奇数；原生结构不变，接口不支持时如实报告。 |
| `control-branch` · 文件存在分支 | 使用原生条件判断 {input_dir}/status.txt 是否存在，存在时写“存在”到 {output}，否则写“不存在”；不能在创建时把判断结果写死。 | 同一流程把待检查路径改成 {input_dir}/absent.txt，保留原生条件分支结构。 |
| `edit-insert` · 中间插入节点 | 创建流程将“结构测试”写入 {output}，然后读取该文件，保存并运行。 | 同一个流程在写入和读取之间插入等待 1 秒，保留两个原节点 ID，预览差异并运行，不能追加到末尾或重建应用。 |
| `edit-delete` · 删除中间节点 | 创建流程将“结构测试”写入 {output}，等待 2 秒，然后读取文件，保存并运行。 | 同一个流程删除中间等待节点，保留写入和读取节点 ID、顺序和参数；预览后保存并运行。 |

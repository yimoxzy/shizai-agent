# 发布 `0.7.32`

本版将结构化网页采集规划改为通用的 native-first 约束：

- 意图分析只识别通用的父子、主从和嵌套记录关系，不包含具体站点或业务选择器。
- 模型可以通过 `collection_shape=hierarchical` 声明层级数据；组件由实时目录能力决定。
- 层级采集必须拆成父记录采集、子记录采集和关系对齐阶段，未完成的计划不会写入设计器。
- 平面采集仍由模型根据实时页面证据选择原生组件或有验证依据的替代方案。
- 允许明确声明阶段的多个原生采集节点，同时继续拒绝普通流程中的重复采集节点。

本版包含 MCP、CLI、浏览器桥接程序和浏览器扩展载荷。安装后请重启 MCP 客户端；浏览器扩展目录如已加载，重新加载该目录以取得对应载荷。

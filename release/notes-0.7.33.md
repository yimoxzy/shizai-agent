# 发布 `0.7.33`

修复停止流程后红色拾取层、运行遮罩和进度胶囊的清理误报：

- 只有收到原生成功回执才报告界面已关闭；超时、拒绝或没有回执时返回未知状态与重试提示。
- 拾取层待清理状态跨进程保存，重启与会话过期不会将未确认的清理变成成功。
- 停止采集支持应用 ID，并允许清理已删除项目目录的遗留会话。
- 分别报告运行停止与界面清理结果；精简 MCP 返回值保留 `false` 和 `ui_cleanup_complete`。
- 隔离旧导航测试的浏览器桥接，防止单元测试访问用户当前扩展。

修复为通用生命周期管理，不含站点、业务或页面选择器。本版保留 `0.7.32` 的原生优先采集规划约束。

安装包包含 MCP、CLI、浏览器桥接程序与扩展载荷。更新后客户端需重新加载 MCP 进程；安装版版本号不代表当前对话已经加载新代码。

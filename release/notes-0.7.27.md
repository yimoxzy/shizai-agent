发布 `0.7.27` Windows x64 包。

本版本包含面向一句话 RPA 生成和持续编辑的 MCP 优化：

- 普通文件、表格和网页请求可直接路由到原生 RPA 设计流程。
- 设计回执提供明确的下一步工具、恢复提示和压缩后的运行状态。
- 网页流程支持先打开浏览器、扫描页面、捕获元素，再绑定到原生组件。
- 同一应用的参数编辑支持预览、版本校验、保存、回读和运行证据。
- 实时组件目录优先返回紧凑摘要，再按实际组件读取契约，减少模型上下文。
- 增加组件组合、网页现场和持续编辑测评资料及回归测试。

验证：完整测试 `471 passed`；公开测评报告记录了网页打开/捕获链路和当前桌面调试通道限制。
发布资产仅包含 Windows x64 编译文件、安装说明、注册脚本和 SHA-256 校验文件。

# 发布 `0.7.31`

本版修复 MCP 流程运行后浏览器标签页持续累积的问题：

- `WebBrowser_CreateV3(openNewTab=true)` 的流程会自动追加 `WebBrowser_CloseWeb_V2`，只关闭该流程创建且仍归属原变量的网页对象。
- MCP 扩展用项目专属 owner key 管理设计标签页；重复打开会复用同一页，成功、失败、停止和异常终态都会清理 MCP 自己创建的页面。
- `wait=false` 的流程通过 `shizai_rpa_status` 返回写权限清理动作，避免只读状态查询暗中操作浏览器。
- 用户已有页面不会按 URL 或激活状态猜测归属，也不会杀掉 Chrome 进程；MCP 自己创建的标签页即使处于激活状态，也会按归属正常关闭。

边界：原生关闭组件位于主流程末尾，中途异常或强制停止可能跳过它；设计标签页清理不能替代原生运行页面的异常清理。无法证明归属的旧页面不会自动关闭。扩展不可用时的旧 Chrome 打开方式也不具备标签页归属证据。

浏览器扩展版本为 `0.1.11`，重新安装 `0.7.31` 后请在 Chrome/Edge 的扩展页重新加载安装目录中的 `browser-extension`。
